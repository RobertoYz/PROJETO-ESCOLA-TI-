📱 Como testar e instalar no seu smartphone Android:

1
Modo Web / PWA (Mais rápido, sem instalar nada): Abra o link pelo Chrome do celular (ou escaneie o QR Code acima). Toque no menu dos 3 pontinhos do Chrome e escolha "Adicionar à tela inicial" ou "Instalar aplicativo". Ele vira um app nativo no celular!
2
Instalação do APK Nativo: Clique no botão "Baixar APK Android" diretamente pelo celular. Ao concluir o download, toque na notificação para instalar e confirme a permissão para "Instalar fontes desconhecidas" no Android.
3
API em Tempo Real: O app já está configurado por padrão para conectar diretamente com o servidor de produção em nuvem. Se precisar alterar o IP ou testar localmente, clique no ícone de ⚙️ engrenagem no topo do app.
