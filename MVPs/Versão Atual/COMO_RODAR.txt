======================================================================
           PROJETO ANJO NEXUS - GUIA PASSO A PASSO SIMPLIFICADO
======================================================================

Este guia rápido explica exatamente como ligar e rodar o projeto
na sua máquina no dia a dia.

⚠️ AVISO IMPORTANTE SOBRE OS ARQUIVOS .env E .env.docker:
Por motivos estritos de segurança da informação, os arquivos ".env"
(usado na execução manual em "back/.env") e ".env.docker" (usado na
execução via Docker em "MVPs/Versão Atual/.env.docker") NÃO são
enviados ao GitHub, pois contêm chaves reais de API (Inteligência
Artificial, AbacatePay, Ngrok e SMTP Gmail).
👉 PARA PROFESSORES, AVALIADORES E COLEGAS DE EQUIPE: Os arquivos
".env" e ".env.docker" originais, completos e já configurados para
rodar o sistema de imediato estão à disposição mediante solicitação
direta aos membros do grupo (Ademar, Pedro ou Roberto).

Você pode escolher entre DOIS MODOS para iniciar o sistema localmente:
  - MODO A: Rodar tudo automaticamente com 1 comando via DOCKER (Novo)
  - MODO B: Rodar manualmente pelo terminal com XAMPP (Método Clássico)


======================================================================
MODO A: COMO RODAR PELO DOCKER (AUTOMÁTICO COM 1 COMANDO)
======================================================================

----------------------------------------------------------------------
PASSO 1 (DOCKER): ABRIR O APLICATIVO DO DOCKER NO COMPUTADOR
----------------------------------------------------------------------
1. Abra o aplicativo "Docker Desktop" no seu computador (Windows/Mac).
2. Aguarde alguns segundos até o ícone da baleia ficar estável (verde
   no canto inferior esquerdo do Docker Desktop, indicando "Engine running").
   *Obs.: Sem o aplicativo do Docker Desktop aberto e iniciado, os
   comandos abaixo não funcionarão.*

----------------------------------------------------------------------
PASSO 2 (DOCKER): CONFIGURAR O ARQUIVO .env.docker
----------------------------------------------------------------------
1. Abra um terminal (PowerShell ou CMD) e entre nesta pasta "Versão Atual":
   cd "MVPs/Versão Atual"

2. Configure o arquivo ".env.docker":
   - Se você recebeu o ".env.docker" pronto da equipe (Ademar, Pedro ou
     Roberto), basta colar o arquivo dentro da pasta "MVPs/Versão Atual/".
   - OU, se quiser criar a partir do arquivo de exemplo, rode o comando:
     copy .env.docker.example .env.docker
     (No Linux/Mac ou Git Bash: cp .env.docker.example .env.docker)
     Em seguida, abra o arquivo ".env.docker" criado e preencha as chaves
     das IAs (GEMINI_API_KEY, GROQ_API_KEY, DEEPSEEK_API_KEY), AbacatePay
     (ABACATEPAY_API_KEY, ABACATEPAY_WEBHOOK_SECRET) e MAIL_PASSWORD.

----------------------------------------------------------------------
PASSO 3 (DOCKER): SUBIR O SISTEMA COMPLETO COM 1 COMANDO
----------------------------------------------------------------------
Ainda dentro da pasta "MVPs/Versão Atual", execute:

   docker compose --env-file .env.docker up --build

O Docker irá subir sozinho:
  - Banco de Dados MySQL 8.0 (na porta 3307 para não conflitar com o XAMPP)
  - Criação automática das tabelas e planos (migrate:fresh --seed)
  - Servidor da API Laravel (http://127.0.0.1:8000)
  - Agendador de tarefas e assinaturas em segundo plano (scheduler)
  - Robôs/Spiders de captura de editais (FINEP, FAPESC, FAPESP, etc.)
  - Servidor Front-end Nginx pronto para usar!

👉 Acesse o sistema no navegador em:
   http://localhost:5500/paginas/login.html (ou http://localhost:5500)

💡 PRECISO DO NGROK PARA TESTAR O PAGAMENTO ABACATEPAY?
   NÃO! Com o comando padrão acima ("docker compose --env-file .env.docker up --build"),
   o cadastro, a geração do checkout PIX/Cartão no AbacatePay e a ativação da
   conta (ao clicar para verificar o pagamento no sistema) JÁ FUNCIONAM 100%
   sem precisar do Ngrok, pois o próprio Back-end consulta a API do AbacatePay!
   Você só precisa do "--profile ngrok" se quiser testar o túnel externo de
   webhook no domínio estático NGROK_DOMAIN (esophagus-swifter-cultivate.ngrok-free.dev).
   Nesse caso, mantenha o NGROK_AUTHTOKEN preenchido no .env.docker e lembre-se:
   o plano gratuito do Ngrok permite apenas 1 túnel ativo por vez nesse domínio.

Comandos extras do Docker (se precisar):
- Para subir incluindo também o túnel do Ngrok (exige NGROK_AUTHTOKEN no .env.docker):
  docker compose --env-file .env.docker --profile ngrok up --build
- Para desligar os containers do Docker:
  docker compose down
- Para desligar e apagar/resetar o volume do banco de dados do Docker:
  docker compose down -v


======================================================================
MODO B: COMO RODAR MANUALMENTE PELO TERMINAL (XAMPP + TERMINAIS)
======================================================================

----------------------------------------------------------------------
PASSO 1: LIGAR O BANCO DE DADOS (MySQL)
----------------------------------------------------------------------
1. Abra o programa "XAMPP Control Panel".
2. Na linha do "MySQL", clique no botão "Start".
3. Verifique se a palavra "MySQL" ficou com fundo verde e se a porta
   3306 está ativa.

(Dica: O banco já foi criado com o nome "anjo_nexus" e já está 
com as tabelas e planos prontos).


----------------------------------------------------------------------
PASSO 2: ABRIR O SERVIDOR DA API (Terminal 1)
----------------------------------------------------------------------
1. Abra um terminal (PowerShell ou CMD).
2. Entre na pasta do backend digitando:
   cd "C:\Users\Pedro Emanuel\Downloads\PROJETO-ESCOLA-TI-\MVPs\Versão Atual\back"

3. Inicie o servidor da API digitando:
   php artisan serve

4. Mantenha essa janela aberta! A API estará funcionando em:
   http://127.0.0.1:8000


----------------------------------------------------------------------
PASSO 3: LIGAR A FILA DA INTELIGÊNCIA ARTIFICIAL (Terminal 2)
----------------------------------------------------------------------
1. Abra um SEGUNDO terminal (não feche o primeiro!).
2. Entre na mesma pasta:
   cd "C:\Users\Pedro Emanuel\Downloads\PROJETO-ESCOLA-TI-\MVPs\Versão Atual\back"

3. Inicie o processador de filas digitando:
   php artisan queue:work

4. Mantenha essa janela aberta! Ela serve para processar os editais,
   extrair dados dos PDFs e rodar a IA em segundo plano.


----------------------------------------------------------------------
PASSO 4: ABRIR O FRONTEND (Sua Tela Visual)
----------------------------------------------------------------------
1. Vá até a pasta:
   C:\Users\Pedro Emanuel\Downloads\PROJETO-ESCOLA-TI-\MVPs\Versão Atual\front

2. Dê dois cliques no arquivo "index.html" para abrir no seu navegador
   (Google Chrome, Edge, etc.).

Pronto! A tela vai carregar e se conectar à sua API automaticamente.


----------------------------------------------------------------------
PASSO 5 (OPCIONAL): CAPTURAR EDITAIS DA FAPESC OU FINEP
----------------------------------------------------------------------
Se quiser encher a sua tela com novos editais reais capturados da internet:

1. Abra um TERCEIRO terminal.
2. Entre na pasta do back:
   cd "C:\Users\Pedro Emanuel\Downloads\PROJETO-ESCOLA-TI-\MVPs\Versão Atual\back"

3. Para buscar editais da FAPESC, execute:
   php artisan spider:fapesc

4. Para buscar editais da FINEP, execute:
   php artisan roach:run FinepSpider

Assim que o robô terminar de capturar, o Terminal 2 (da fila) vai 
analisar os editais com a IA. Depois, basta atualizar a página no seu 
navegador (tecla F5) para ver os editais na tabela!


----------------------------------------------------------------------
O QUE FAZER SE PRECISAR RESETAR O BANCO?
----------------------------------------------------------------------
Caso queira apagar tudo e recriar o banco do zero:
   php artisan migrate:fresh --seed
