1 - Abrir a pasta de dowloads:

cd Downloads

--------------------------------------------------------------------

2 - Clonar o projeto:

git clone https://github.com/RobertoYz/PROJETO-ESCOLA-TI-.git

--------------------------------------------------------------------

3 - Entrar na pasta do projeto:

cd PROJETO-ESCOLA-TI-

--------------------------------------------------------------------

4 - Mover para a branch correta (USA O NOME DA SUA BRANCH!):

git checkout EDTAN-x-Fazer-Descrição-Caso-de-Uso-e-Diagrama

--------------------------------------------------------------------

EXTRA: Caso a branch esteja desatualizada (outro merge foi feito antes dela), faça:

git pull origin main (vai atualizar a sua branch com o que está na main)

--------------------------------------------------------------------

5 - Coloque e modifique os arquivos que quiser na pasta

--------------------------------------------------------------------

6 - Volte ao cmd e prepare os arquivos adicionados:

git add .

--------------------------------------------------------------------

7 - Faça a mensagem de commit com a chave gerada pelo Jira (COPIA A CHAVE DO COMMIT NO JIRA, ELA TEM QUE APARECER PELO MENOS 1 VEZ NA MENSAGEM DO COMMIT):

git commit -m "EDTAN-X: Adiciona documentos de caso de uso e diagramas"

--------------------------------------------------------------------

CASO erre na mensagem do commit, ANTES de fazer o push, faça:

git commit --amend -m "TICKET-123: sua mensagem de commit aqui"

--------------------------------------------------------------------

8 - Só finalizar fazendo o push:

git push
