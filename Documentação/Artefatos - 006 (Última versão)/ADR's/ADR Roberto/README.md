# Matriz Consolidada de Registros de Decisões Arquiteturais (ADRs) — Roberto (Versão 006)

Este catálogo reúne as 34 Decisões Arquiteturais de **Back-end** sob responsabilidade de **Roberto** (`EDTAN-80`, `EDTAN-104`, `EDTAN-121`, `EDTAN-148`, `EDTAN-156`, `EDTAN-157`, `EDTAN-158`, `EDTAN-160`, `EDTAN-164`, `EDTAN-208` e `EDTAN-280`) no ecossistema **Anjo Nexus**, detalhando a modelagem relacional Multi-Tenant, camadas de serviço e validação, autenticação Stateless via Laravel Sanctum, integração com AbacatePay API v2 e Webhooks, algoritmos de regularização e exclusão em cascata de contas pendentes, recuperação de senha via SMTP, gestão de perfil do Consultor, arquitetura de cadastro/edição de Startups, refatoração e consolidação de migrations (schema squashing), isolamento de provedores externos via padrão Adapter, encerramento de conta com Hard Delete sob a LGPD e gestão do ciclo de assinatura com renovação acumulativa e idempotência PIX.
